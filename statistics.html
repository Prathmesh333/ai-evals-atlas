Uncertainty and fair comparisons

Find out whether a gain is meaningful or just variation in the test.

Learning level 55–603 min read + practice1 diagram · 1 exercise

Report an interval

If a model passes 80 of 100 tasks, the observed success rate is 80%. That number is not the exact population success rate. A 95% Wilson interval is approximately 71.1% to 86.7% under independent Bernoulli sampling.

A confidence interval describes the long-run coverage of a procedure. It does not mean that 95% of individual tasks fall inside the interval. It also does not fix biased sampling, contaminated labels, or an invalid grader.

Repeated trials on the same task are correlated through task difficulty. Do not treat every trial as an independent new task. Resample at the task or user level when that is the independent unit. State the sampling assumptions.

Compare on the same tasks

Use paired comparisons when two systems answer the same cases. Record which system wins on each case. A paired bootstrap resamples cases and recomputes the score difference. Preserve all related trials within each resampled case.

For binary outcomes, inspect the discordant pairs: tasks only A passes and tasks only B passes. McNemar's test uses those disagreements for a paired comparison under its assumptions. Similar aggregate scores can hide very different error patterns.

Choose the minimum useful improvement before the experiment. A tiny statistically detectable gain can still cost too much to deploy. Report the effect size, uncertainty, runtime cost, and operational relevance.

Avoid selection traps

Testing many prompts and reporting only the winner inflates apparent performance. Use a separate final holdout or account for multiple comparisons. Document how many candidates you considered.

A fixed sample size avoids repeatedly checking results until a threshold is crossed. If you need sequential monitoring, choose a method designed for repeated looks. An ordinary fixed-sample interval is not automatically valid after optional stopping.

For rough planning at worst-case proportion 0.5, n ≈ 1.96² × 0.25 / e² estimates the sample size for margin e. A five-percentage-point margin needs about 385 independent cases. Clustering, rare failures, and subgroup estimates can require more.

Try it yourself

Use the statistics playground with 80/100 and 800/1000. Compare the intervals even though both observed rates are 80%.

Does a narrow confidence interval remove dataset bias?

No. An interval quantifies sampling uncertainty under assumptions. A large biased sample can give a precise estimate of the wrong population.
