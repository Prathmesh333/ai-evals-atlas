Chapter 06 / Build a model

Fine-tuning and post-training

Choose between prompting, retrieval, supervised tuning, and preference optimization.

Learning level 40–453 min read + practice2 diagrams · 1 exercise

Choose the intervention

Prompting changes instructions without changing weights. Retrieval supplies external evidence at request time. Fine-tuning changes model parameters using examples. These methods solve different problems and can be combined.

If facts change frequently, retrieval often provides a more direct update path than retraining. If the model repeatedly uses the wrong response format, supervised examples can help. First measure the failure so you can test whether the intervention fixes it.

Supervised fine-tuning trains on desired responses. For an assistant dataset, apply the intended chat template and define which tokens contribute to loss. Accidentally training on the wrong roles changes the learning objective.

Adapt efficiently

Low-rank adaptation, or LoRA, trains small additional matrices while keeping most base weights fixed. Quantization stores weights with fewer bits. Quantized adaptation can reduce memory needs, but memory still includes activations, optimizer state, and runtime buffers.

Keep an untuned baseline. Evaluate task gains alongside general instruction following, refusal behavior, and language coverage. A narrow training dataset can improve a target metric while damaging other behavior.

Record the base checkpoint, tokenizer, adapter settings, dataset revision, and training configuration. An adapter alone does not identify a reproducible model. Test the actual merged or served representation if that is what users receive.

Preferences and rewards

Preference optimization uses comparisons between outputs or a reward signal. Reinforcement learning from human feedback commonly includes preference data and a learned reward model. Direct Preference Optimization uses preference pairs through a different objective.

A reward is a proxy for desired behavior. If the reward favors length, the model can learn to write more without becoming more correct. Evaluate with graders and examples that are independent of the training reward.

Keep evaluation sets separate from demonstrations, preference pairs, and reward-model training data. Measure regressions after each stage. A single final score cannot reveal which training stage introduced a failure.

Try it yourself

Classify five failures as missing knowledge, formatting, retrieval, reasoning, or tool execution. Choose one intervention and an evaluation for each.

Does a better training reward guarantee better user outcomes?

No. The reward can be incomplete or exploitable. Measure independent task outcomes and inspect examples where reward and correctness disagree.
