Chapter 05 / Build a model

Train a tiny transformer

Move from character counts to a neural model with a controlled training loop.

Learning level 30–403 min read + practice2 diagrams · 1 exercise

A small neural experiment

The optional transformer lab uses PyTorch and a byte vocabulary. It trains a small causal transformer from random initialization. The architecture uses two layers, four attention heads, and a hidden size of 64. The context contains 64 bytes.

Bytes keep the vocabulary fixed at 256 symbols. A byte model spends more positions on some characters than others. Compare its loss with other byte models under the same conventions. Do not compare that loss directly with the character bigram lab.

Run python -m pip install -r labs/requirements-transformer.txt in a virtual environment. Then run python labs/tiny_transformer.py --steps 50 for a smoke test. This command checks the training path. It does not train a useful assistant.

Read the training loop

The input batch contains byte sequences. The target batch contains the same sequences shifted by one position. The model predicts a distribution at each position. The causal mask blocks access to future positions.

The loop clears gradients, computes loss, backpropagates, clips gradients, and updates weights with AdamW. Validation runs with dropout disabled and gradient recording disabled. The script saves the checkpoint with the lowest validation loss.

The final test evaluation uses that checkpoint. The report records the configuration, dependency version, and input hashes. A seed helps repeat the experiment, but hardware and numerical kernels can still affect reproducibility.

Scale only after the checks pass

Try to overfit a very small training batch first. If the model cannot reduce that loss, inspect target shifting, masks, optimizer settings, and gradients. Then train on a larger, diverse corpus with document-level splits.

Track tokens processed rather than steps alone. Batch size and sequence length change the amount of data in a step. Log learning rate, training loss, validation loss, gradient norms, and throughput. Save optimizer state when you need exact resumption.

For larger experiments, study nanoGPT and the Hugging Face course. Their examples illustrate practical training components. They do not supply a reproducible recipe for a proprietary frontier model. The included script is an educational baseline, not a production training stack.

python labs/tiny_transformer.py --steps 50

Try it yourself

Train the same configuration twice with different seeds. Compare validation loss and generated samples. Keep the test set out of architecture selection.

Why must validation disable dropout?

Dropout adds random masking during training. Disabling it measures the model's normal inference behavior and reduces avoidable variation.
