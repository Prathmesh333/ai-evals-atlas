Start without a background in AI

The first chapters define the terms. Basic Python helps with the labs. The small-model and evaluation labs need no GPU, API key, or external dataset.

Read the evidence with its limits

This notebook focuses on language models and their surrounding systems. Frontier-lab sections use public sources. No public guide contains every proprietary method or every AI subfield.
