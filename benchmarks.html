Reference / Benchmarks

Know what the score means.

A benchmark is useful when its task and protocol match your question. Start with the measurement, then inspect the limitations.

9 benchmarks and suites

Knowledge

MMLU ↗

Multiple-choice questions across academic subjects.

Read the metricAccuracy under a specified prompting and scoring protocol.
Keep this limitationKnowledge recall does not establish practical task reliability.
Reasoning

GPQA ↗

Graduate-level questions written by domain experts.

Read the metricAccuracy; identify the exact subset and answer protocol.
Keep this limitationExpert questions cover a specific distribution, not all scientific work.
Reasoning

GSM8K ↗

Grade-school mathematical word problems.

Read the metricCorrectness of the extracted final answer.
Keep this limitationAnswer extraction, calculator use, and exposure to public solutions affect comparisons.
Code

HumanEval ↗

Generate functions that satisfy executable tests.

Read the metricPass@k with a declared sampling budget.
Keep this limitationPassing tests does not prove general correctness. Generated code requires isolation.
Code

SWE-bench ↗

Resolve real repository issues in controlled environments.

Read the metricResolved-task rate for a named variant.
Keep this limitationAgent scaffolding, tools, dependencies, and budgets can dominate differences.
Reasoning

BIG-bench ↗

A broad collection of language-model tasks.

Read the metricTask-specific metrics; name the selected tasks.
Keep this limitationAn aggregate depends on task selection and weighting.
Truthfulness

TruthfulQA ↗

Answer questions that elicit common misconceptions.

Read the metricUse the metric and format defined by the chosen protocol.
Keep this limitationTruthfulness on this set does not establish factual reliability in every domain.
Agents

τ-bench ↗

Tool-using agents interact with simulated users and domain policies.

Read the metricTask success and repeated-trial reliability.
Keep this limitationThe user simulator, tools, and task version are part of the evaluated system.
Evaluation suite

HELM ↗

Evaluate models across scenarios and multiple measurement dimensions.

Read the metricScenario-specific metrics and transparent run configurations.
Keep this limitationA suite is not one universal score. Inspect individual scenarios and tradeoffs.
