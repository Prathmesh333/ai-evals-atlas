Reference / Benchmarks

Know what the score means.

A benchmark is useful when its task and protocol match your question. Start with the measurement, then inspect the limitations.

22 benchmarks and suites

Knowledge

MMLU ↗

Multiple-choice questions across academic subjects.

Read the metricAccuracy under a specified prompting and scoring protocol.
Keep this limitationKnowledge recall does not establish practical task reliability.
Reasoning

GPQA ↗

Graduate-level questions written by domain experts.

Read the metricAccuracy; identify the exact subset and answer protocol.
Keep this limitationExpert questions cover a specific distribution, not all scientific work.
Reasoning

GSM8K ↗

Grade-school mathematical word problems.

Read the metricCorrectness of the extracted final answer.
Keep this limitationAnswer extraction, calculator use, and exposure to public solutions affect comparisons.
Code

HumanEval ↗

Generate functions that satisfy executable tests.

Read the metricPass@k with a declared sampling budget.
Keep this limitationPassing tests does not prove general correctness. Generated code requires isolation.
Code

SWE-bench ↗

Resolve real repository issues in controlled environments.

Read the metricResolved-task rate for a named variant.
Keep this limitationAgent scaffolding, tools, dependencies, and budgets can dominate differences.
Reasoning

BIG-bench ↗

A broad collection of language-model tasks.

Read the metricTask-specific metrics; name the selected tasks.
Keep this limitationAn aggregate depends on task selection and weighting.
Truthfulness

TruthfulQA ↗

Answer questions that elicit common misconceptions.

Read the metricUse the metric and format defined by the chosen protocol.
Keep this limitationTruthfulness on this set does not establish factual reliability in every domain.
Agents

τ-bench ↗

Tool-using agents interact with simulated users and domain policies.

Read the metricTask success and repeated-trial reliability.
Keep this limitationThe user simulator, tools, and task version are part of the evaluated system.
Evaluation suite

HELM ↗

Evaluate models across scenarios and multiple measurement dimensions.

Read the metricScenario-specific metrics and transparent run configurations.
Keep this limitationA suite is not one universal score. Inspect individual scenarios and tradeoffs.
Safety

HarmBench ↗

Evaluate red-team methods and target-model defenses under a declared protocol.

Read the metricAttack or defense outcomes using the selected task set and classifier.
Keep this limitationThe threat model, attack budget, and grader affect the result. It is not a general certificate of safety.
Truthfulness

SimpleQA ↗

Short factual questions with a specified answer-grading procedure.

Read the metricCorrectness and abstention categories under the chosen implementation.
Keep this limitationJudge reliability and dataset scope constrain factual-reliability claims.
Agents

WebArena ↗

Browser agents complete tasks in controlled web environments.

Read the metricTask success based on the benchmark's state and outcome checks.
Keep this limitationBrowser state, environment version, action interface, and budgets are part of the result.
Multilingual

Belebele ↗

Reading-comprehension tasks across many languages.

Read the metricAccuracy for each named language and split.
Keep this limitationReading comprehension does not establish conversational, cultural, or translation quality in that language.
Knowledge

MMLU-Pro ↗

A revised multiple-choice benchmark with harder questions and expanded answer options.

Read the metricAccuracy on the named version and subject set.
Keep this limitationThis is not interchangeable with MMLU. Match the prompt and scoring protocol.
Instructions

IFEval ↗

Instruction-following tasks with verifiable constraints.

Read the metricPrompt-level and instruction-level compliance under the specified strict or loose checks.
Keep this limitationConstraint compliance does not establish factual correctness or general helpfulness.
Code

EvalPlus ↗

Additional test coverage for supported code-generation tasks.

Read the metricFunctional correctness using the named augmented test set.
Keep this limitationTest suites remain finite. Passing more tests does not prove correctness for all inputs.
Code

LiveCodeBench ↗

Code tasks collected over time with several evaluation scenarios.

Read the metricTask-specific success for a declared release and collection window.
Keep this limitationTask freshness reduces some exposure risks but cannot prove that a model has never seen related material.
Long context

LongBench ↗

Tasks for long-context comprehension and reasoning.

Read the metricTask-specific scores for the named benchmark version.
Keep this limitationInput length, truncation, evidence position, and prompt settings affect results.
Multimodal

MMMU ↗

Questions that combine visual material and subject knowledge.

Read the metricAccuracy under the selected task and input protocol.
Keep this limitationThe result does not cover all vision tasks and says nothing by itself about audio or video.
Agents

τ²-bench ↗

Agent interaction with users, tools, and domain environments.

Read the metricTask outcomes and repeated-trial reliability for the selected domain.
Keep this limitationKeep the simulator, tool state, rules, and task revision fixed across comparisons.
Performance

MLPerf Inference ↗

System performance under specified workloads and quality requirements.

Read the metricScenario-specific throughput or latency with the required quality constraints.
Keep this limitationA custom timing script is not an official MLPerf result. Read the submission rules before claiming compliance.
Preference

MT-Bench ↗

Multi-turn conversational evaluation using a specified judging protocol.

Read the metricRubric scores from the declared judge and setup.
Keep this limitationJudge version, position, verbosity, and self-preference effects can influence the score.
