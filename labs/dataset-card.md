# Evaluation dataset card

## Purpose and population
What decision does this dataset support? Which tasks, users, languages, dates, and environments does it represent?

## Provenance and permission
Record source, collection method, ownership, license or permitted use, consent where applicable, and any restrictions on distribution.

## Sampling and splits
Record the sampling unit, grouping rules, time boundaries, sample counts, and the roles of each split.
Describe duplicate detection, near-duplicate checks, benchmark exposure, and unknown contamination risks.

## Fields and labels
Define the input, expected answer, acceptable variants, slice fields, and metadata hidden from the model.
Link the labeling guide. Record reviewer qualifications, disagreement handling, and known ambiguous cases.

## Coverage and limitations
Report slice counts, excluded populations, synthetic-data share, rare-case sampling, and any population weights.
List claims this dataset cannot support.

## Version and maintenance
Record a version, file hashes, owner, change history, access policy, and the trigger for refresh or retirement.
