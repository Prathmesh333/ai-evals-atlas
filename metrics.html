Chapter 08 / Build evaluations

Choose metrics that match the task

Use accuracy, precision, recall, ranking metrics, and cost without hiding tradeoffs.

Learning level 50–553 min read + practice2 diagrams · 1 exercise

Classification and extraction

Precision is TP / (TP + FP). Recall is TP / (TP + FN). F1 is the harmonic mean of precision and recall. Define the positive class and the treatment of zero denominators.

Suppose a detector finds 8 of 10 actual errors and flags 4 correct items. Precision is 8/12, or 66.7%. Recall is 8/10, or 80%. F1 is about 72.7%. The preferred balance depends on the cost of missed errors and false alarms.

Macro averages give each class equal weight. Micro averages pool decisions before calculation. Report class support so a high aggregate does not hide failure on a rare class. For structured extraction, measure individual fields and complete-record correctness.

Generation and retrieval

Exact match checks a fully constrained answer. Token overlap metrics can help compare summaries, but lexical similarity does not establish factual correctness. A fluent paraphrase can be correct with little overlap. A copied sentence can be factually wrong in context.

For retrieval, recall@k asks whether relevant items appear in the first k results. Mean reciprocal rank rewards placing a relevant result early. nDCG supports graded relevance and discounts results at lower positions. Define how relevance labels are obtained.

Evaluate retrieval and answer generation separately. A correct answer produced without supporting evidence can still fail a grounded-answer requirement. Measure citation support at the claim level, not only whether the response contains a link.

Operational and calibrated performance

Report latency percentiles, failure rate, token usage, and cost per successful task. An average latency can hide a slow tail. Compare the same workload, concurrency, hardware, and caching conditions.

Calibration measures whether predicted confidence corresponds to observed correctness. A system that assigns 80% confidence should be correct on about 80% of comparable predictions. Use reliability diagrams, Brier score, or other proper scoring rules when probabilities are meaningful.

Selective prediction allows abstention. Plot error against coverage as the confidence threshold changes. A system can reduce errors by answering fewer requests. Report both values so abstention does not look like a free improvement.

Try it yourself

Calculate precision, recall, and F1 for TP=18, FP=6, FN=12. Explain which metric matters most if a missed defect is expensive.

A system improves accuracy by refusing half its tasks. What else must you report?

Report coverage, refusal rate, and the scoring rule for unanswered tasks. Accuracy on answered tasks alone hides the reduced service coverage.
