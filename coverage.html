Curriculum / Coverage audit

The complete guide map.

A connected path through AI evaluation and benchmarking: learn the concepts, build experiments, inspect evidence, and make a defensible decision.

Complete here means an end-to-end practical curriculum with explicit learning outcomes. It does not mean every benchmark, every mathematical proof, every industry requirement, or undisclosed lab methods.

Chapter-by-chapter outcomes

Use each exercise as a checkpoint. Completing the reading alone is not a demonstration of practical mastery.

What an evaluation measures

The machine learning essentials

03 / Foundations

Evaluate prediction models beyond LLMs

Choose a classification task and a forecasting task. State the prediction unit, baseline, split rule, metric, and deployment threshold for each.

04 / Foundations

Tokens, transformers, and generation

For target-token probabilities 0.5 and 0.25, compute average negative log-likelihood. Exponentiate it to obtain perplexity, about 2.83.

05 / Build a model

Build your first small model

Run the lab on two different text domains. Train on one domain and test on the other. Explain the change in loss and unknown-character rate.

06 / Build a model

Train a tiny transformer

Train the same configuration twice with different seeds. Compare validation loss and generated samples. Keep the test set out of architecture selection.

07 / Build a model

Fine-tuning and post-training

Classify five failures as missing knowledge, formatting, retrieval, reasoning, or tool execution. Choose one intervention and an evaluation for each.

08 / Build evaluations

Design an evaluation dataset

Write 20 cases for a receipt parser: 10 routine cases, 5 difficult layouts, and 5 unanswerable inputs. Keep the categories explicit.

09 / Build evaluations

Design an experiment before running it

Write a one-page protocol for comparing two support assistants. Include the estimand, randomization unit, primary metric, missing-answer policy, and stopping rule.

10 / Build evaluations

Choose metrics that match the task

Calculate precision, recall, and F1 for TP=18, FP=6, FN=12. Explain which metric matters most if a missed defect is expensive.

11 / Build evaluations

Uncertainty and fair comparisons

Use the statistics playground with 80/100 and 800/1000. Compare the intervals even though both observed rates are 80%.

12 / Build evaluations

Build and validate your graders

Write a three-level rubric for a grounded answer. Include one example that sounds confident but cites evidence that does not support its claim.

13 / Build evaluations

Human evaluation and preference studies

Create a rubric with three independent dimensions for a research answer. Write one tie example and one example requiring specialist review.

14 / Build evaluations

Run public benchmarks correctly

Choose two published results for the same benchmark. Compare versions, prompts, tools, inference budgets, and metrics before comparing the numbers.

15 / Build evaluations

Evaluate reasoning, code, and instructions

Write five tests for a generated median function, including an empty-input policy and an even-length input. State how you will isolate execution.

Evaluate retrieval and agents

Your complete evaluation project

Complete the report template in labs/report-template.md. Include at least three representative failures and one unresolved limitation.

What needs specialist treatment

Robotics, embodied-control safety, causal inference, formal verification, privacy guarantees, and regulated domain validation each require additional methods and domain expertise. This guide introduces the evaluation principles that connect to those areas. It does not replace their specialist curricula.

Frontier-lab sections explain public disclosures and explicitly labeled engineering synthesis. Private training mixtures, hidden test sets, and internal release decisions cannot be reconstructed from public leaderboard scores.

Finish with a reproducible decision

Complete the capstone and report template. Include the task contract, data provenance, versions, budget, grader checks, uncertainty, failure analysis, and release conditions.

Start with the dataset card template and example grading rubric. Adapt and validate the rubric for your task before using its scores to make a decision.
