Chapter 02 / Foundations

The machine learning essentials

Understand data, parameters, loss, and generalization before training anything.

Learning level 10–153 min read + practice1 diagram · 1 exercise

How a model learns

A parameter is a number the training algorithm can change. A prediction uses the current parameters. A loss function measures how wrong that prediction is for the training example. An optimizer updates parameters to reduce the loss.

For linear regression, the prediction is ŷ = wx + b. Mean squared error averages (ŷ − y)². Gradient descent changes w and b in the direction that reduces the loss. Neural networks apply the same idea to many connected operations.

A classification model predicts a distribution over classes. Cross-entropy penalizes low probability on the correct class. Lower training loss means the model fits the training examples better. It does not establish performance on new examples.

Three data splits

Use training data to fit parameters. Use validation data to select settings and checkpoints. Use test data for the final estimate after you freeze those choices. Repeated decisions based on test scores turn the test set into validation data.

Split by the unit that can leak information. For customer tickets, keep each customer or conversation in one split when those relationships matter. For forecasting, split by time. Random rows can place nearly identical records on both sides.

Overfitting occurs when a model learns details that do not generalize. Compare training and validation loss. A falling training loss with a rising validation loss is a common warning. Reduce capacity, improve data, regularize, or stop earlier.

Probability and measurement

A sample is a subset of a population. A metric computed on that sample is an estimate. Different samples produce different estimates even when the model does not change.

Accuracy is correct predictions divided by all predictions. A model that always predicts the common class can have high accuracy on an imbalanced dataset. Compare it against that constant baseline.

Keep units explicit. Latency might mean seconds per request or milliseconds per generated token. Throughput measures completed work per unit of time. Neither number has meaning without workload and hardware details.

Try it yourself

Create 100 labels with 95 negatives and 5 positives. Calculate accuracy for a model that always predicts negative. Explain why 95% is misleading.

Which split should select the learning rate?

The validation split. Keep the final test split out of model and hyperparameter selection.
