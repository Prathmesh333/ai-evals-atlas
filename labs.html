Practice / Runnable experiments

Learn by running the experiment.

Four Python labs connect the notebook to training, stored-prediction evaluation, and a real model endpoint. Each lab has a clear scope and records its result.

Run these commands from the repository root. Python 3.10+ is required. Only the transformer lab needs PyTorch. The website itself needs no installation.
git clone https://github.com/Prathmesh333/ai-evals-atlas.git
cd ai-evals-atlas
Lab 01

Train a character language model

No dependencies beyond Python. The script fits unigram and bigram models, selects smoothing on validation text, and evaluates the final choices on test text.

python labs/tiny_lm.py

The report contains validation losses, test perplexity, input hashes, and the unknown-character rate. Read labs/runs/tiny-lm.json. A generated sample is not a quality score.

Lab 02

Train a tiny byte transformer

A CPU smoke experiment with 137,216 parameters: two layers, four heads, and a 64-byte context. Use more data and training for a meaningful language experiment.

python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS / Linux: source .venv/bin/activate
python -m pip install -r labs/requirements-transformer.txt
python labs/tiny_transformer.py --steps 50

The script selects the lowest-validation-loss checkpoint, evaluates it on test data, and writes a checkpoint plus a JSON report. The tiny sample corpus cannot train a useful assistant.

Lab 03

Evaluate two sets of predictions

No API calls. The dataset and both prediction files are synthetic teaching fixtures. The script scores every case, including missing answers.

python labs/evaluate.py

Expected result: baseline 7/12, candidate 10/12. The paired bootstrap interval crosses zero, so the small example does not establish a reliable improvement. Read labs/runs/evaluation.json.

Download evaluate.py ↓ · Read source ↗
Lab 04

Collect predictions from a model endpoint

Start a compatible local model server first. This standard-library client sends case inputs without the answer key. Hosted endpoints are optional and can charge for requests.

python labs/collect_predictions.py --model YOUR_LOCAL_MODEL --base-url http://127.0.0.1:1234/v1 --output labs/runs/local-model

The run writes predictions.json and manifest.json. Missing responses count as task failures. Read the real-model chapter for baseline and candidate collection, credentials, and endpoint compatibility.

Make the experiment yours

  1. Replace the sample data with permitted, separate document splits.
  2. Define a task-specific scoring rule before inspecting candidate results.
  3. Save the dataset version and model configuration with the report.
  4. Explain failures and limits in the report template.
