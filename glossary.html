Reference / Terminology

One term, one meaning.

The terms used throughout the notebook, explained in plain language.

Ablation
An experiment that removes or changes one component to study its contribution.
Accuracy
The fraction of scored cases with a correct prediction under the declared rule.
Agent
A system that selects actions and uses observations across multiple steps.
Attention
A learned operation that combines information from accessible sequence positions.
Baseline
A reference system used to judge whether a proposed change adds value.
Benchmark
A shared set of tasks and a protocol for scoring results.
Calibration
Agreement between stated confidence and observed correctness across comparable predictions.
Checkpoint
Saved model parameters and, when included, training state.
Confidence interval
An interval produced by a procedure with a stated long-run coverage under its assumptions.
Contamination
Evaluation information influencing training or selection in a way that undermines the intended measurement.
Context window
The token capacity available to a model request under its implementation.
Cross-entropy
A loss that penalizes low predicted probability on the target outcome.
Dataset shift
A difference between the distribution used for development and the distribution encountered later.
Elicitation
Choosing prompts, tools, or other conditions to reveal a model capability.
Evaluation harness
Software that runs tasks, obtains model outputs, applies graders, and records results.
Fine-tuning
Updating a pretrained model using additional training examples.
Grader
A rule, program, model, or human process that assigns a score.
Holdout
Data reserved from a specified training or selection process.
Inference
Using a trained model to produce outputs.
LoRA
Low-rank adaptation, which trains additional low-rank matrices while freezing most base weights.
Logit
An unnormalized model score before a probability transformation such as softmax.
Negative log-likelihood
The negative logarithm of the probability assigned to an observed target.
Overfitting
Learning patterns that improve fit on development data but do not generalize to the target population.
Pass@k
The probability or estimated rate of at least one success within k attempts under a specified protocol.
Perplexity
The exponential of average negative log-likelihood when natural logarithms are used.
Precision
The fraction of positive predictions that are correct.
Prompt injection
Instructions in untrusted content that attempt to change the system’s intended behavior.
RAG
Retrieval-augmented generation: retrieving evidence for use during response generation.
RLHF
Reinforcement learning from human feedback, a family of methods that use human feedback to guide optimization.
Recall
The fraction of actual positive cases that a system identifies.
Regression
A deterioration in a measured behavior after a change.
Slice
A defined subset of evaluation cases, such as a language or document type.
Temperature
A sampling setting that changes the concentration of the token distribution.
Token
A unit of input or output represented by a tokenizer.
Trace
A record of an execution, including available outputs, tool calls, observations, and state changes.
Validation set
Data used to choose model settings, checkpoints, or other development decisions.
